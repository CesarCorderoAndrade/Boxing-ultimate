# Proyecto Boxeo Java

## Java boxing game with graphical interface

This project is a 2D boxing game developed in Java using Swing for the graphical interface.  
It was created as part of coursework focused on object-oriented programming and GUI design.

The game includes player movement, hit detection, health tracking, and basic animation logic.

## Technologies Used
- Java
- Swing (GUI)
- Object-Oriented Programming
- Event Handling

## Project Structure
proyecto-boxeo-java  
    .settings/  
    bin/  
    src/  
    .classpath  
    .project  
    .gitattributes  

## How to Run
1. Open the project in Eclipse or any compatible Java IDE.
2. Make sure the JDK is properly configured.
3. Run the main class located in `src/`.
4. The game window will launch with interactive controls.

# Videojuego de boxeo en Java con interfaz gráfica

Este proyecto es un juego de boxeo en 2D desarrollado en Java utilizando Swing para la interfaz gráfica.  
Fue creado como parte del curso centrado en programación orientada a objetos y diseño de interfaces.

El juego incluye movimiento del jugador, detección de golpes, seguimiento de salud y lógica básica de animación.

## Tecnologías utilizadas
- Java  
- Swing (interfaz gráfica)  
- Programación orientada a objetos  
- Gestión de eventos  

## Estructura del proyecto
proyecto-boxeo-java  
    .settings/  
    bin/  
    src/  
    .classpath  
    .project  
    .gitattributes  

## Cómo ejecutarlo
1. Abre el proyecto en Eclipse o cualquier IDE compatible con Java.
2. Asegúrate de tener el JDK configurado correctamente.
3. Ejecuta la clase principal ubicada en `src/`.
4. Se abrirá la ventana del juego con controles interactivos.
